Product Signal Control Tower

Synthetic portfolio prototype

Evidence before automation.

A human-reviewed n8n workflow turns product signals into a structured, evidence-backed brief and a recorded decision.

Read the project documentation

Architecture

Two model calls, one accountable decision.

1. Intake and minimize

Normalize the signal, limit personal data, and detect exact replays.

2. Extract and ground

Validate structured extraction, retrieve reviewed evidence, then draft a brief.

3. Review and route

Pause for a human decision; persist the decision and route an approved artifact to an outbox.

PostgreSQL includes pgvector schema support; OpenTelemetry and Jaeger support traces. Retrieval quality has not been evaluated here.

Controls

Design for failure as well as flow.

  • Validate model output and degrade safely when a response is unavailable or malformed.
  • Use replay checks to reduce duplicate processing.
  • Keep model evidence separate from human approval and downstream actions.
  • Sanitize unexpected errors and use synthetic inputs for demonstration.

Local demo boundary: the review wait link has no incoming authentication. Anyone with the link can act; add authentication, authorization and network controls before a real deployment.
